BProgram Essentials

사업 핵심

B.01
대상 기업 / Eligibility
선판매계약
제작기업
배급사·방송국 등과 콘텐츠 선판매계약을 체결하고 문화상품을 제작하려는 콘텐츠기업. 게임·영화·방송·애니·공연·음악·만화·캐릭터·출판 9개 장르.
B.02
지원 규모 / Scale
완성보증
최대 50억
콘텐츠 제작완성 전 단계 기획·제작자금 보증. 기업당 15억(방송용·수출용 콘텐츠는 최대 50억). 완성·인도 시 판매대금·수익금으로 상환.
B.03
신청 방식 / Method
추천(KOCCA)
→ 보증(신보·기보)
콘텐츠가치평가센터 온라인 신청 → 콘진원 추천심사(콘텐츠 우수성) → 보증기관(신보·기보) 보증심사 → 보증서 발급 → 대출.
보증 한도 / 선행 요건
Terms
구분내용비고
보증한도15억원 내외방송용·수출용 콘텐츠 최대 50억원
선판매 이내 신청총제작비 30% 이상 조달 확정자기자금·투자·선판매 합산
선판매 초과 신청총제작비 50% 이상 조달 확정장르 특성 탄력 적용
보증기간콘텐츠 제작 완료 시까지판매대금·수익금으로 상환
사전 체크 / 유의Notes
  • 사전 체크리스트 1~5(금융권 연체·당좌부도·체납·책임경영 위반 등) 저촉 시 신청 불가
  • 자기자본 전액잠식·부채비율 550% 초과는 신청 가능하나 보증한도 제한
  • 비추천 시 6개월 내 재신청 불가 · 추천서 유효기간 6개월
CEligibility Checklist

자격 체크리스트

공통 자격 / Common
  • 배급사·방송국 등과 콘텐츠 선판매계약 체결 후 제작하려는 기업
  • 게임·영화·방송·애니·공연·음악·만화·캐릭터·출판 9개 장르
  • 총제작비 30%(선판매 이내)/50%(선판매 초과) 이상 조달 확정
지원 제외 / Exclusion
  • 최근 금융권 연체·당좌부도·신용관리등급·권리침해(가압류 등)
  • 국세·지방세 체납·4대보험 체납·CB 연체
  • 법인 책임경영 위반(실제경영자 대표이사·최대주주 아닌 경우)
우대 가점 / Bonus Points
  • 방송용·수출용 콘텐츠는 보증한도 최대 50억원까지 신청 가능
