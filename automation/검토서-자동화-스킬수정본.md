## 수정 2. PDF "공고문 원본 보기" 모달 — base64 폐기 → pdfs/ 상대경로

`## PDF "공고문 원본 보기" 모달` 섹션 전체를 아래 내용으로 교체.
**핵심 변경**: base64 임베드(`__PDF_B64_PLACEHOLDER__` + `scripts/embed_pdf.py`)를 폐기하고,
PDF를 레포 `pdfs/`에 올린 뒤 `var PDF_DATA="pdfs/<슬러그>.pdf"` 상대경로로 참조한다.

### 섹션 도입부 (교체본)

```markdown
검토서에 공고문 원본 PDF 모달을 넣을 때, 아래 방식만 사용한다.
**PDF는 base64로 본문에 임베드하지 않는다.** 대신 레포 `pdfs/` 폴더에 실제 PDF 파일을
올리고, HTML은 상대경로로 참조한다. (2026-07 결정: 검토서가 계속 쌓이므로 HTML을
가볍게 유지하고, 레포도 pdfs/ 호스팅 방향으로 통일. base64 임베드·`embed_pdf.py`는 폐기)

### PDF 호스팅 — pdfs/ 상대경로 참조

1. 다운로더가 만든 공고문 PDF를 레포 `pdfs/<슬러그>.pdf`로 복사한다
   (슬러그는 검토서 파일명과 동일, 예: `pdfs/171-ifez-esg-consulting.pdf`).
   파일명은 **ASCII 슬러그**로 둔다 — 한글·공백·특수문자는 href URL 인코딩 문제를 피한다.
2. HTML의 JS에는 상대경로만 둔다: `var PDF_DATA = "pdfs/<슬러그>.pdf";`
3. `scripts/embed_pdf.py`(base64 주입)는 더 이상 쓰지 않는다.
```

### 런타임 동작 규칙 (교체본)

```markdown
### 런타임 동작 규칙 (모달 표시)

1. **PDF는 `PDF_DATA` 상대경로로 참조** — `var PDF_DATA="pdfs/<슬러그>.pdf"`.
   레포(GitHub Pages)에 HTML과 pdfs/가 함께 올라가므로 상대경로가 정상 resolve된다.
   다운로드용 표시 파일명은 `var PDF_NAME`에 한글로 둔다.
2. **iframe.src에 PDF_DATA를 그대로 넣는다** — `frame.src = PDF_DATA`.
3. **모달 표시는 `.open` 클래스** — `.pdf-modal{display:none}` +
   `.pdf-modal.open{display:flex}`를 함께 두면 `modal.classList.add('open')`로 열린다.
4. **다운로드·닫기 필수** — 다운로드 버튼은 `dl.href=PDF_DATA; dl.download=PDF_NAME`,
   닫기는 닫기버튼·배경클릭·ESC로 처리하고 닫을 때 `frame.src=''`로 비운다.
```

### 코드 패턴 (교체본)

```js
var PDF_DATA = "pdfs/171-ifez-esg-consulting.pdf";   // ← 레포 pdfs/ 상대경로 (base64 아님)
var PDF_NAME = "2026년 OO 지원사업 공고.pdf";           // 다운로드 파일명(한글 OK)

(function () {
  var modal = document.getElementById('pdfModal'),
      frame = document.getElementById('pdfModalFrame'),
      dl    = document.getElementById('pdfDownloadBtn');
  window.openPdfModal = function () {
    if (!modal) return;
    frame.src = PDF_DATA;
    dl.href = PDF_DATA; dl.setAttribute('download', PDF_NAME);
    document.getElementById('pdfModalTitle').textContent = PDF_NAME;
    modal.classList.add('open');
    document.body.style.overflow = 'hidden';
  };
  function closePdf() {
    if (!modal) return;
    modal.classList.remove('open'); frame.src = ''; document.body.style.overflow = '';
  }
  var cb = document.getElementById('pdfModalClose');
  if (cb) cb.addEventListener('click', closePdf);
  if (modal) modal.addEventListener('click', function (e) { if (e.target === modal) closePdf(); });
  document.addEventListener('keydown', function (e) { if (e.key === 'Escape') closePdf(); });
})();
```

모달 HTML/CSS와 트리거 버튼(`onclick="openPdfModal()"`)은 `references/example-form.html`을
참고하되, `PDF_DATA`만 pdfs/ 상대경로로 바꾼다.

### 주의사항 항목 10 (교체본)
